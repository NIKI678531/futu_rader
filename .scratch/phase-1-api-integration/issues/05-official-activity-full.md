# 05: 官号动态整页接 API

**What to build:** `/official` 整页脱离设计源镜像，全部内容由后端供数，并且逐字比对干净。这是第一个**完整**走完 API 的页面（01 只打通了一张表）。

**Blocked by:** 01, 03, 04

**Status:** ready-for-agent

## 验收标准

- [ ] `etfMentionsFor(account, range)` 在 `backend/core/` 实现并暴露端点
- [ ] 页面全部内容由 `buildRange` / `officialPosts` / `etfMentionsFor` 驱动，不再触碰镜像
- [ ] 移除屏幕里对演示生成器 `R.hash` 的调用，**移除后页面输出逐字不变**；04 的静态守卫 ① 对本页转绿
- [ ] 阵营三分互斥语义保持，**不与 KOL 页的「提自家含 both」统一**。两个页面问的不是同一个问题：官号页问「这条动态归哪个阵营」（用于分布统计，一条只能归一类），KOL 页问「这个 KOL 提没提我们」（ADR-0013 O4）。它看起来像不一致，实际上不是
- [ ] 「提及 ETF」按 `ETF_MENTION_RULE`（按出现次数累加）。**不得**与市场域的评论去重口径混用——两者语义相反
- [ ] 02 的 `/official` diff clean
- [ ] 页面上出现的每个 `0` 都能追溯到一个真实为零的后端字段
- [ ] 该页所需端点全部 200，无 5xx
- [ ] 断开后端 → **屏级**错误条，明确说服务连不上；不是一屏空数据、不是满屏 `0`。屏级错误与字段级「暂不可用」在 UI 上必须是两种不同的东西
