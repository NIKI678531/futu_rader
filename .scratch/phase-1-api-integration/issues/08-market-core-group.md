# 08: 市场域基础组——产品池 / 全市场排名 / 基准 / 观测

**What to build:** 板块总览的 KPI 区与产品表里所有数量类字段改由后端供数。其中最要紧的是**全市场评论量排名和热力图色阶标尺由后端算好、前端只过滤显示**——这张工单是铁律 3 的落地与验收现场。对产品团队的意义很具体：「第 12 名」从此是一个可以对外引用的稳定事实，而不是随手一点筛选就变的数字。

**Blocked by:** 03, 04

**Status:** ready-for-agent

## 验收标准

- [ ] `pool(range)` `ranks(range)` `benchmark(code, range)` `observe(code, range, salt?)` 实现并暴露端点
- [ ] `ranks` 基于**完整活跃 ETF 池**计算，下发排名 map + total（PRD §3.8、§4.1）
- [ ] `delta` 作为**内嵌形状**返回 `{abs, pct, dir}`，输入缺失时整体为 `null`。`delta` **不是端点**；**前端不得自己算环比**（铁律 1）
- [ ] `null` 的 `delta` → 环比位渲染长文案「数据暂不可用」，短徽章位渲染「暂不可用」
- [ ] **排名稳定性验收**：任选一个产品记下其全市场评论量排名 → 依次切板块、切范围、切搜索、切开关 → 排名数字**始终不变**
- [ ] **色阶标尺验收**：热力图色阶标尺在筛选前后不变，同一格颜色不因可见集变化而变。PRD §4.1 逐字：「板块、范围、搜索与开关只改变可见范围；排名与色阶标尺始终来自全市场」
- [ ] 基准区间与时间桶由后端下发，**前端不自行算桶**（PRD §5 逐字）
- [ ] 04 的六态断言在这些字段上通过；每个 `0` 可追溯到真实为零的后端字段
- [ ] 本单**不要求** `/sector` 整页 diff clean——叙述类字段在 09
