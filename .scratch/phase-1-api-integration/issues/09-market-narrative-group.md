## Comments

**验证**：后端 275 个测试（新增 30：`test_narrative.py` 28 ＋ `test_meta.py` 2）、六态 36 条、五页 6 次逐字比对（`/sector` 三态）、4 条静态守卫、`npm run build` 干净。`/sector` 三种状态下 21 次接口调用全部 200，无 pageerror。

**六个函数切成六个端点，但不是六种粒度。** `hotSummaryFor` 按区间**整池**下发（`GET /hot-summaries?range=`），门面按代码取用：它在榜单行循环里，一屏 120 行按产品切端点就是 120 次串行往返（同步 Suspense 一次只解决一个 read）。这是取集合里的元素，不是「视图内聚合」，与 ADR-0015 无关，同 `observe` → `pool`。`themesFor` 保留三参签名 `(code, range, polarity)`，但端点一次给 `{positive, negative}`：两处调用点都是正负各取一次，切成两个端点等于白挨一次往返。其余四个是按产品的端点，只在抽屉打开时才打。

**这一组的 bug 长什么样。** 基础组盯的是数，这一组盯的是**状态与措辞**。`empty` / `unavailable` / `na` 在响应里的 `list` 一模一样（都是空的），页面上却是三句不同的话：「查过了，没有」「该有值但取不到」「同业产品不纳入识别」。所以 `competitors` / `compliance` 带 `status`，`test_the_three_empty_states_are_only_told_apart_by_status` 是反着写的一条断言——它证明**光看列表分不出来**，谁把 status 省掉或者前端只判 `list.length === 0`，三句话就塌成一句。演示数据四态都有活样本（ok 13 / empty 47 / unavailable 1 / na 59），少一态没人测，写歪了也不会红。

**热议总结的文案由后端给，不由前端按 status 拼。** 三态各一句：ok 是观点本身，`low_sample` 是「样本不足，暂无主流观点」，`unavailable` 是「数据暂不可用」。让屏幕按枚举拼，等于把 PRD §3.6 的措辞实现成第二份（铁律 1），而这份最容易写歪。另有一条专门的断言钉住 `unavailable` 那句里不许出现 `0`——`sample` 确实是 0，但它是占位，不是「我们查过了，一条都没有」的结论。

**`shareOfNegative` 各类别之和小于 100% 是口径本身的形状**，不是漏算：分母是消极总数，而可归类、可行动的那部分 ≠ 全部消极观点。写成断言（`0 < total < 100`）是为了拦住两种「修好它」的冲动——把余数补成「其他」（凭空造类别），或者把分母换成已归类之和（每一类都虚高）。

**`/meta` 新增两项。** `statusLegend` 每条补 `bg`/`fg`：六态里只有「暂不可用」和「待确认」是警示色，「暂无内容」是蓝（检查过了、确实没有，不该看着像出事）。这个映射留在屏里，五个屏迟早各写各的。先例是 SECTORS 的 `hue`/`tint`，同属 ADR-0004 的口径常量。`rules.hotSummary` 逐字下发，要害是「须为观点而非正负面判断」——实现成「整体偏正面」，这一列就变成了紧挨着的正面／负面两列的复述。门面里 `legendOf` 把 `{key, text}` 映成屏幕要的 `{k, v}`，形状转换只收在 `/meta` 的 getter 里。

**diff harness 加了「展开态」（`views`）。** 原来它只抓默认页面状态，而这一页数据最密的两块都是收起的：快速详情抽屉（本单五个函数里的五个全在里面）和「口径与数据状态」面板（六态图例、S6 去重口径、热度公式、热议总结口径——本单三条逐字验收标准的现场）。只比默认状态就等于把它们排除在「逐字一致」之外，绿灯的含义比字面上小一圈。现在 `/sector` 比三次：693 / 905 / 715 段文字，全部逐字一致。

一个必须记下来的坑：**第一版展开态是假绿的**。`grab()` 的稳定判据是「文本长度连续两次不变」，而点开抽屉后前端要现取五份数据，250 ms 的轮询在这个空档里当场判稳，抓到的是没打开的页面——报出来是 212 处差异全在设计源那侧。修法不是加 sleep，是让展开操作自己等一个**只有展开后才有**的字（抽屉等「当前舆情总结」，面板等图例里那句「字段应有值，但当前数据源未提供或尚未核验。」）。顺带也解决了另一半问题：点了个没反应的元素同样会得到「两边一致」的绿灯——这和 08 那次排名脚本的假绿是同一类错误，第二次遇到了。

**「断开后端 → 屏级错误条」不在这张 diff 里验**，它在 `six-state.mjs` 的对照组：把 `/api/v1/**` 全部 abort 掉，断言页面出「后端服务连不上」的屏级错误条，且**不再**渲染「CSOP产品讨论热度」「全市场活跃 ETF」这些骨架文字。把断网渲染成满屏「数据暂不可用」是最坏的一种误导——市场团队会以为是数据源缺字段，接着照常看那些还在的数字。

**没做的事**：`pool.globalMax` 仍然是下发了但没人读（08 已记）；抽屉打开是 6 次串行往返，够用就没优化——它只在点开时发生，不在首屏路径上。
