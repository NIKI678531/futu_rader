# ADR-0032 — 单区间 AI 队列与低样本观察

- **状态**：已接受
- **日期**：2026-10-06
- **取代**：[ADR-0031](0031-daily-full-refresh-single-queue.md) §1 中六个区间同时入队，以及原来的 D1 优先级

管理页只允许先选择一个 D1／D2／D7／D14／D30／MTD 区间再提交，且任一分析排队或运行时拒绝另一个手动区间；不再提供“一键补齐全部”接口。每日自动任务只排 D7、D1、D2，领取顺序为 D7 → D1 → D2，长区间保留为手动选择，避免 D14／D30／MTD 积压遮蔽短区间完成度。

低于 `LOW_SAMPLE` 仍然表示“不能输出整体倾向”，但不再等于首页只能显示占位文字：只要至少有一条已确认相关评论，`hot_summary` 就生成一条带证据的样本观察，页面保留「样本不足」前缀；生成文案不得使用“主流”“多数”或“趋势”。模型若返回无证据或其他无效输出，则从已提供的真实证据截取一条“有评论提到……”并标为待确认，保证不会退回无内容占位。产品页的整体舆情总结仍受原阈值约束。

帖子标注仍以完整原文作为幂等指纹。单篇正文超过网关输入限制时，发送确定性的首尾摘录并显式标记 `content_truncated=true`；模型必须把结果标为待确认，证据仍回到完整原文定位。这样长帖不会永久失败，也不会伪装成读过完整正文。
