# ADR-0010 — `annotations` 表与第一期最小 AI 标注管线

- **状态**：已接受
- **日期**：2026-09-09
- **相关**：[ADR-0001](0001-dual-provider.md)、[ADR-0009](0009-worker-scope.md)、[ADR-0013](0013-prd-open-items-o1-o8.md)

> **2026-09-11：下面的第 1、2、3 条已被 [ADR-0017](0017-ai-annotation-pipeline-production.md) 取代。**
> 本 ADR 是在拿到 API 之前写的；跑过真实数据后，单表形态、Claude Haiku 4.5 的模型选择、
> 以及 `confidence < 0.7` 阈值三处都不成立。**第 4 条（口径归属）不变。**
> 这里不改正文 —— 它记录的是当时基于当时信息作出的判断。

## 背景

市场域与账号域大量字段在原始 schema 里**根本不存在**，必须由 AI 从文本产出：

- 评论级：**态度**（积极／中性／消极，PRD §3.4）
- 帖子级：**类型双标签**（内容形式 × 操作方向，`TYPE_RULE`）、**AI 摘要**（≤60 字，`SUMMARY_NOTE`）
- 派生：观点主题、动态负面类别、重点舆情（需合规关注）

原本的方案是「第一期只建表位、不建管线，AI 派生字段一律 `unavailable`」。**产品决定推翻它**：既然已经接入真实数据，**有真实数据就先展示出来**，不要让市场域两个屏空着。

## 决策

### 1. `annotations` 表：AI 标注结果的唯一落点

```
target_type   'feed' | 'comment'
target_id
kind          'attitude' | 'post_type' | 'direction' | 'summary' | 'neg_category' | 'compliance'
value
confidence
model
created_at
```

`backend/core/` 的所有 AI 派生字段**一律从这张表读**，不从别处算。

### 2. 第一期跑最小标注作业

范围限定在**瘦库内**（120 只标的 × 最近 N 天），由 worker 调度：

- 评论 → 态度三分类
- 帖子 → 类型双标签 ＋ 操作方向 ＋ ≤60 字摘要

模型默认 **Claude Haiku 4.5**（`claude-haiku-4-5-20251001`）——量大、单条短、结构化输出，成本与延迟是主要约束；抽样复核用更强的模型。模型标识写进 `annotations.model`，换模型时旧结果可辨认、可重跑。

### 3. `lowConfidence` 阈值现在有生效对象了

`confidence < lowConfidence`（当前 0.7）的标注结果，前端渲染为**「待确认」**——PRD §3.6 的第六态。这个阈值原本在「不建管线」的方案下是空转的。

### 4. 口径归属不变

AI 产出的是**事实**（「这条评论是消极的」）。把事实聚合成**指标**（情绪净值、赞踩比、热度、排名）仍然只在 `backend/core/`。**铁律 1 不破。**

## 后果

- 引入 API 调用成本与耗时，规模取决于瘦库里最近 N 天的评论量——[ADR-0008](0008-dump-import-and-slim-db.md) 的第 2 条导入后验证会给出这个数，**跑标注前必须先看它**。
- 标注质量决定市场域的可信度。需要一个抽样复核环节，且演示时如实说明「AI 标注、未经人工确认」——这也正是「待确认」态存在的原因。
- **摘要语言**：[ADR-0013](0013-prd-open-items-o1-o8.md) O3 仍待客户确认，但第一期真出摘要就得有个默认值。实现取「**随原文语言**」（依 `raw_json.original_lang`，繁文出繁摘、简文出简摘）。这是**实现默认值，不是替客户拍板**。
- 图片帖第一期仍不覆盖（`SUMMARY_NOTE` 逐字如此），走 `NO_TEXT` 文案。

## 否决的备选

- **只建表、不建管线**（原建议）：`mysql` provider 下市场域两个屏大面积「暂不可用」。产品判断：既然真实数据已经在手，先展示出来比先保守更有价值。
- **不建 `annotations` 表、字段直接写进 feeds/comments**：标注会重跑、会换模型、会有多个 kind，写进事实表就把「事实」和「推断」混在一行里——那正是铁律 2 想防的那类混淆。
