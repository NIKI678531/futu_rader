# ADR-0033 — 业务页隐藏汇总新鲜度，板块态度条独立展示

- **状态**：已接受
- **日期**：2026-10-07
- **取代**：[ADR-0031](0031-daily-full-refresh-single-queue.md) §5 中「业务页为 `stale` 生成物显示『待更新』徽章」的可见层约定

`stale` 仍是 API 与分析管理的有效运维状态：旧生成物照常下发，不会被隐藏、改写或当成缺失；Admin 和处理进度仍展示对应计数，但可见名称统一改为「需重算」。面向产品／市场用户的业务页不再渲染「待更新」徽章或后缀；这是展示决策，不是删除 freshness 数据契约。

业务页不再显示通用的「部分数据」标签。评论覆盖状态、`≥` 下限、源数据覆盖率与 AI 覆盖率继续保留并照常驱动数值和缺失态；本决策只移除无法告诉用户“哪部分缺失”的泛化徽章，不把部分覆盖改写为完整。

产品监控的「产品相关 KOL」表删除「主要态度」列及其低样本脚注；KOL 来源、提及数、摘录和原文证据保留。「南方东英发行商观点」是产品资源 `/products/<code>/issuer-opinions`，只读取与当前 ETF 的 `subject_code` 相同且仍有严格内容路由的评论。评论正文唯一命中一个产品时优先归给该产品；评论未命中产品时，只有父帖也唯一命中一个产品才允许归属；多产品父帖下的泛公司评价不广播到任一产品。无相关观点时返回空集合并隐藏模块，未完成分析则保持 `unavailable`；同一评论 ID 在单产品内只展示一次。模块默认只显示 API 原顺序中最新的前 4 条消极评价，其余条目经用户展开后才显示，收起后回到该预览集。

板块总览榜单的态度小条使用独立的**展示门槛**：筛后评论达 5 条时，有已识别的积极／消极计数就按两者比例画绿红条；态度块非空但两者均为 0 时画灰条。态度块为 `null` 仍表示尚未分析或源未提供，继续显示「暂不可用」，不伪装成已分析后的灰条。这不改变 `LOW_SAMPLE=10`：10 条仍是是否输出整体倾向的后端门槛，5 条只决定紧凑榜单是否给出视觉分布。
