# ADR-0035 — D0 当天区间与手动分析链路

- **状态**：已接受
- **日期**：2026-10-08
- **补充**：[ADR-0012](0012-frozen-demo-anchor.md)、[ADR-0032](0032-single-range-analysis-and-low-sample-observation.md)

## 背景

既有 `d1` 以最近一个完整香港自然日为右端，因此只能表达“昨日”。页面需要在其左侧增加
“当天”，并允许数据管理页查看和手动运行同一套 Layer A／Layer B 分析。把 `d0` 直接映射到
`anchor` 会让“当天”和“昨日”读取同一天；用服务器系统日期又会在数据源滞后时制造一个看似
真实的全零窗口。

## 决策

1. 新增 `d0`，标签“当天”，按小时展示 24 个自然小时桶；它不是滚动 24 小时。
2. `anchor` 继续只表示最近一个完整源数据日。`d0` 的当前数据日来自数据库实际到达的最新
   HKT 帖子时间（历史导入可由 `data_max_ts` 提供），且必须晚于 `anchor`。演示 provider
   使用冻结的 `NOW_DATE/NOW_TIME`。不读取服务器日期兜底。
3. `/ranges/d0` 始终可以给出完整的日期与桶描述；若尚无当天事实，其余业务端点返回
   `200 + unavailable/null`，前端以完整、可交互的空状态组件承接，不显示“数据接入中”，
   也不把未知量填成 0。
4. 有当天事实时，总量表示截至 `dataThrough` 的已观测事实；晚于该时刻的小时桶保持 `null`。
   基准为前一自然日，标签沿用“较昨日同期”。
5. `d0` 可从数据链路管理页单独入队，复用现有单区间队列、抽取、Layer A、Layer B、进度和
   完整度链路。抽取上限取所选窗口的最晚 `to`，不能再硬截到完整日 `anchor`。
6. 每日 08:00 自动队列仍为 D7 → D1 → D2；D0 与 D14／D30／MTD 一样由管理页手动选择，
   避免未闭合日反复抢占每日完整区间任务。

## 后果

- 同一天内新事实到达时会把 `d0` 生成物标为需重算；重复运行依靠输入指纹保持幂等。
- D0 没有事实或分析尚未完成时，页面仍完整展示，但相关字段按六态显示暂不可用／暂无内容。
- D1 及其他历史档位的 anchor、自动调度顺序和既有口径不变。
