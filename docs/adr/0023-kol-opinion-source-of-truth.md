# ADR-0023 — KOL 专用观点结论是产品相关 KOL 的事实来源

- **状态**：已接受
- **日期**：2026-09-17
- **取代**：ADR-0020 §6 中「`kol_mentions_for` 由态度标注 ∩ KOL 作者名派生」

产品相关 KOL 与 KOL 详情的「其他产品观点及操作」统一读取 `kol_comment_opinion` 的现行结论：只有非空 `kol_summary` 才表示这位 KOL 确实对该产品表达了观点；通用 `comment_product` 的态度结论只用于汇总主要态度，不再决定该观点是否存在。两套 Prompt 对同一短评论可能给出不同的相关性判断，继续取交集会让已经生成的 KOL 观点在产品页消失。

KOL 评论标注升级为 v2，同时产出评论自身的 `post_type`、观点摘要与操作。详情表过滤模型明确写下的“无观点”占位；已检查但没有有效观点返回空态，任务未覆盖才返回不可用。类型不得从父帖继承，因为父帖可能由另一位作者发布，父帖类型不等于 KOL 评论的内容形式。
