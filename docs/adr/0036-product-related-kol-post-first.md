# ADR-0036 — 产品相关 KOL 以相关原帖为主

- **状态**：已接受
- **日期**：2026-10-08
- **取代**：[ADR-0023](0023-kol-opinion-source-of-truth.md) 中“评论观点是产品相关 KOL 唯一事实来源”的决定

产品相关 KOL 以合作 KOL 发布且明确关联当前产品的原帖为主数据源，经 KOL 专用结论确认的评论观点作为补充；没有相关原帖但有确认评论观点的账号仍保留。页面先按每位 KOL 最新相关原帖时间倒序，同刻按 KOL 名；仅评论账号排后，并在组内按最新评论时间倒序。这让“最新发帖”与排序、展示时间及代表内容指向同一条原帖，而不会被一条更新的补充评论改写。

列表中的「帖子摘要」只使用最新相关原帖已有的 AI 单句总结，不以标题、首句或正文摘录回退；摘要尚未生成或模型明确判定无摘要时显示「暂不可用」。原文证据始终保留原始引文或正文，不以摘要替换，确保列表概览与可核验证据各自表达真实语义。

## 结果

- 产品页与 KOL 页共用相关原帖口径，仅评论账号仍可见但不会排到原帖账号之前。
- 接口增加可空的 `latestPostAt` 与 `representativeSummary`；`lastMentionedAt`、`representativeExcerpt` 与原文证据继续保留，现有消费方可渐进迁移。
- 直接复用已有帖子摘要，不新增模型任务或数据库迁移。

## 放弃的方案

- 继续以评论观点作唯一来源：会漏掉 KOL 自己发布的相关原帖，且与 KOL 页事实不一致。
- 按任意最新提及时间排序：一条更新的评论会改写「最新发帖」语义。
- 为产品页新建一套摘要任务：与现有帖子摘要重复，增加运行成本与结论漂移风险。
